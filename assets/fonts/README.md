# Thai-script Pali font

Noto Serif Thai variable font, distributed under SIL Open Font License 1.1.
Source: https://github.com/google/fonts/tree/main/ofl/notoserifthai
Downloaded 26 October 2026. Original file: `NotoSerifThai[wdth,wght].ttf`.
SHA-256: `34a7ad11647c845303aabdde639059806c56b84719e5d2ceb28eb038711bdf53`.
The downloaded file was verified against the Git blob SHA from the repository API.

The unmodified font is self-hosted as `noto-serif-thai.ttf`; license in
`OFL-NotoSerifThai.txt`. No external font service is needed at runtime.
CSS family alias: Pali Thai. Thai Unicode range only; Latin stays in the existing font stack.
Enable OpenType `ss01` to use the font's descenderless ญ/ฐ glyphs for Pali,
including when a nikkhahit is above. Keep `ccmp`, `locl`, `mark`, `mkmk`
for composition and mark placement. Do not replace Unicode characters or delete marks.
